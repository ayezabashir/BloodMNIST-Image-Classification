# BloodMNIST Image Classification Using a Small CNN

A PyTorch-based deep learning experiment for classifying microscopic blood-cell images into eight categories using a lightweight Convolutional Neural Network (CNN).

## Overview

This project implements and evaluates a small CNN trained from scratch on the BloodMNIST dataset. The experiment explores multiclass image classification, data preprocessing, model training, validation-based checkpoint selection, and class-wise performance evaluation.

The workflow is implemented in Python using PyTorch and Google Colab. It includes visualizations and saved evaluation artifacts to support experiment analysis and reproducibility.

## Objectives

- Build a lightweight CNN for biomedical image classification.
- Apply training-set normalization and basic data augmentation.
- Train the model using cross-entropy loss and the AdamW optimizer.
- Select the best checkpoint using validation loss and early stopping.
- Evaluate performance using accuracy, precision, recall, F1-score, ROC-AUC, and confusion matrices.
- Analyze class-wise errors and document the experimental configuration.

## Dataset

**BloodMNIST** is part of the [MedMNIST collection](https://medmnist.com/), a collection of standardized biomedical image datasets designed for machine learning research.

- **Image modality:** Microscopic blood-cell images
- **Image resolution:** 28 × 28 pixels
- **Image channels:** 3 (RGB)
- **Classification task:** Eight-class classification
- **Data splits:** Official training, validation, and test splits

### Classes

1. Basophil
2. Eosinophil
3. Erythroblast
4. Immature granulocyte
5. Lymphocyte
6. Monocyte
7. Neutrophil
8. Platelet

The notebook downloads the dataset through the MedMNIST Python API. The dataset itself is not included in this repository.

**Dataset reference:** Yang et al., *MedMNIST v2: A large-scale lightweight benchmark for 2D and 3D biomedical image classification*, Scientific Data, 2023. [Paper and dataset information](https://medmnist.com/).

## Model Architecture

The CNN is trained from scratch without pretrained weights.

| Component | Configuration |
|---|---|
| Input | 3 × 28 × 28 RGB image |
| Convolutional blocks | 3 |
| Convolution channels | 32, 64, 128 |
| Convolution | 3 × 3 |
| Normalization | Batch Normalization |
| Activation | ReLU |
| Downsampling | Max Pooling |
| Global pooling | Adaptive Average Pooling |
| Regularization | Dropout (0.30) |
| Output | 8 class logits |

The model uses a compact architecture intended to provide a baseline without the computational overhead of a large pretrained network.

## Experimental Setup

| Parameter | Value |
|---|---|
| Framework | PyTorch |
| Environment | Google Colab |
| Random seed | 42 |
| Batch size | 128 |
| Maximum epochs | 30 |
| Optimizer | AdamW |
| Learning rate | 0.001 |
| Weight decay | 0.0001 |
| Loss function | Cross-Entropy Loss |
| Learning-rate scheduler | ReduceLROnPlateau |
| Early stopping patience | 7 epochs |
| Checkpoint selection | Lowest validation loss |

### Preprocessing

- Convert images to tensors.
- Calculate RGB channel means and standard deviations from the training split only.
- Normalize training, validation, and test images using those training-set statistics.
- Apply random horizontal flipping and random rotation of up to 10 degrees during training.
- Do not apply random augmentation during validation or testing.

The official dataset splits are retained to maintain a consistent evaluation protocol.

## Results

The following results are from the reported test evaluation of the baseline CNN.

| Metric | Test result |
|---|---:|
| Accuracy | 94.68% |
| Macro precision | 94.81% |
| Macro recall | 93.59% |
| Macro F1-score | 94.15% |
| Weighted F1-score | 94.66% |

### Class-wise Performance

| Class | Precision | Recall | F1-score |
|---|---:|---:|---:|
| Basophil | 94.83% | 90.16% | 92.44% |
| Eosinophil | 99.20% | 98.88% | 99.04% |
| Erythroblast | 97.08% | 96.14% | 96.61% |
| Immature granulocyte | 85.69% | 88.95% | 87.29% |
| Lymphocyte | 94.96% | 93.00% | 93.97% |
| Monocyte | 92.19% | 83.10% | 87.41% |
| Neutrophil | 94.52% | 98.50% | 96.47% |
| Platelet | 100.00% | 100.00% | 100.00% |

The reported test set contains 3,421 images.

The model achieved its strongest reported F1-scores on eosinophils and platelets. Monocytes had the lowest recall (83.10%), while immature granulocytes had the lowest F1-score (87.29%). These results suggest that class-wise error analysis is important even when overall accuracy is high.

## Reproducibility

The experiment uses a fixed random seed, official dataset splits, training-set normalization, validation-loss-based checkpoint selection, and a saved configuration file.

The `config/experiment_config.json` file documents the main dataset, model, preprocessing, and training settings. Package versions and hardware details should also be recorded for more complete reproducibility.

Small differences may occur across hardware, software versions, and nondeterministic operations.

## Limitations

- Images are only 28 × 28 pixels, which limits the amount of visual detail available to the CNN.
- Results on one benchmark split do not establish generalization to other datasets or clinical settings.
- Perfect test performance on an individual class does not guarantee perfect performance on unseen data.
- The experiment is a research and educational classification project, not a clinically validated diagnostic tool.
